# Ride-Sharing Analytics

## Project Overview

Ride-Sharing Analytics is a data analytics project that analyzes ride-sharing trip data to understand trip performance, revenue, cancellations, driver activity, and customer behavior.

## Dashboard Preview

![Ride Sharing Analytics Dashboard](Images/Ride%20Sharing%20Analytics%20Dashboard.png)

## Technologies Used

- SQL Server / SSMS
- SQL
- Power BI
- Python
- Git & GitHub
- CSV Dataset

## Dataset

The project uses three datasets:

- Drivers
- Riders
- Trips

## SQL Analysis

SQL was used for:
- Database and table creation
- Data insertion
- Data analysis
- Trip and revenue analysis
- Completed and cancelled trip analysis

## Power BI Dashboard

The Power BI dashboard contains:
- Total Trips
- Completed Trips
- Cancelled Trips
- Total Revenue
- Trip Analysis Charts
- Ride-Sharing Performance Insights
